Why this is the gap, not just a new pipeline (see slide 3):
  Existing UQ/anomaly work stops at the first box's output — an alarm
  magnitude to threshold. Existing risk-aware planning starts from the
  THIRD box's assumptions (a trustworthy prediction) without the first
  two. This framework is the one path that doesn't drop the thread
  between them: the SAME calibrated signal Layer 1 validates is what
  Layer 2 rolls through the physical margin — not a generic, assumed-
  correct trajectory.

Two intuitions worth stating plainly:
  → A calibrated interval alone doesn't know when it MATTERS — a wide
    interval on an empty road and the same width near cross-traffic are
    not equally dangerous. Layer 2 exists specifically to make that
    distinction.
  → Which features carry a fault's evidence isn't obvious in advance
    (slide 13) — this is why the pipeline is per-feature, not a single
    collapsed anomaly score, from the start.
