THE BELIEF-DIVERGENCE MECHANISM

The digital twin maintains an independent expectation of what perception
SHOULD report — from HD map assertions, learned nominal patterns, and
vehicle dynamics — and flags a fault when perception diverges from it.

  ┌──────────────────────────────────────────────────────────────────┐
  │  Map-grounded expectation  <--- compare --->  Perception report  │
  │  (e.g., "a signalized                          (what the AV's    │
  │   intersection exists here")                    camera reports)  │
  │                                                                    │
  │  Divergence  →  belief-divergence residual  →  calibrated alarm  │
  └──────────────────────────────────────────────────────────────────┘

The strong form — negative-evidence detection:
  → The map licenses a HARD categorical expectation (a signal exists here)
  → The fault signature is perception failing to report what must be there
  → This is mechanistically different from "the residual is elevated" —
    it's specifically "the system stopped reporting something it should
    have known about"

Epistemic stance — scoped precisely, not a blanket claim:
  → Applies specifically to the TWO map-anchored channels (traffic_light_
    detected as a map fact, traffic_light_discrepancy as the map-vs-
    perception mismatch) — NOT a description of the whole model
  → For those two channels: this is introspection/self-assessment, non-
    circular because the check is against the map, an independent,
    externally-licensed ground truth — not the model grading its own homework
  → Every OTHER predicted feature (position, velocity, steering,
    acceleration) is checked against real ground-truth vehicle state, not
    the map — the map only contributes as route/geometry CONTEXT there, not
    as the verification anchor
  → What's actually novel is not "using an HD map" (common in AV perception/
    planning) — it's using one of its categorical assertions as an
    INDEPENDENT CROSS-CHECK oracle for a single perception channel, not just
    as input context

Divergence-trace schema (what's logged, per timestep, per trial):
  → predicted mean/variance/actual/residual, per feature, uncollapsed
  → map-expectation channel kept separate from perception-report channel
  → ground-truth safety-outcome markers (fatal-moment anchor, MRM trigger)

Two-arm fault injection (unchanged backbone):
  → Arm A (safety disabled): the science condition — faults reach a real outcome
  → Arm B (safety enabled): the ground-truth oracle for lead time — not yet collected
