Why this is the gap, not just a new pipeline (see slide 3):
  Existing UQ/anomaly work stops at the first box's output — an alarm
  magnitude to threshold. Existing risk-aware planning starts from the
  fifth box's assumptions (a trustworthy prediction) without the first
  four. This framework is the one path that doesn't drop the thread
  between them: the SAME calibrated signal Layer 1 validates is what
  Layer 2 optimizes and rolls through the physical margin — not a
  generic, assumed-correct trajectory, and not an independently
  re-derived uncertainty object.

Three intuitions worth stating plainly:
  → A calibrated interval alone doesn't know when it MATTERS — a wide
    interval on an empty road and the same width near cross-traffic are
    not equally dangerous. Layer 2 exists specifically to make that
    distinction.
  → Layer 2 does NOT construct a second, independent reachability set —
    the calibrated interval, swept across the horizon, already IS a raw
    reachable tube. Layer 2's job is optimizing/trimming that tube with
    map and scene cues, in two stages (before rollout / after rollout),
    not re-deriving it from scratch.
  → Which features carry a fault's evidence isn't obvious in advance
    (slide 13) — this is why the pipeline is per-feature, not a single
    collapsed anomaly score, from the start.
