THE DIGITAL TWIN: ST-GAT ARCHITECTURE (updated this session)

Encoder: GCN graph encoder (HD map lanelets) + BatchNorm, fused with a
Transformer temporal encoder + LSTM over a 3-second (30-step, 10Hz) window.

Input features (14, redesigned this session to fix real bugs found in the
prior repo's approach — not anchored to it):
  → Ego state: position (relative displacement, fixed-scale — NOT per-window
    bbox-relative, a scale-inconsistency bug fixed this session), velocity,
    steering, acceleration
  → Traffic light: detected (map fact), state (perception report),
    discrepancy (map-vs-perception mismatch) — the negative-evidence channel
  → Object context: permutation-invariant set encoder (masked mean-pool over
    up to 8 tracked objects), replacing a collapsed nearest-object heuristic
    that silently discarded multi-object information
  → Scene context: adjacent-lane flag, EKF position uncertainty

Output heads (Gaussian mean/variance, or Bernoulli where appropriate):
  → position, velocity, steering, acceleration — Gaussian, beta-NLL weighted
  → traffic_light_state — Gaussian (NEW head this session — previously
    computed as an input but never actually predicted)
  → traffic_light_discrepancy, traffic_light_detected — Bernoulli/BCE

Two real bugs fixed this session (not hypothetical — reproduced and verified):
  → Entity-collapse: TL extraction was pooling across every currently-tracked
    light group instead of the one the vehicle is actually governed by —
    silently muted the model's own strongest signal
  → Missing output heads: the negative-evidence channel (tl_state,
    tl_discrepancy) was computed as an input but had no way to be predicted,
    so no residual/NLL was computable on the signal that matters most

Horizon is a variable, not a fixed hyperparameter — cache/checkpoint paths
are horizon-tagged (h30_30) so a horizon sweep doesn't silently collide.
