# Archive — historical notes, not maintained

Dated working notes and superseded design documents, kept so a past decision
can be traced. They contradict each other and the current design in places
(they record how the thinking moved). Do not treat anything here as current.

Current state lives in three files:
- `docs/architecture.md` — the pipeline design
- `docs/findings.md` — what has been measured, with numbers
- `docs/experiment_plan.md` — what to collect next

Notes from 2026-08-20 onward map to `findings.md` sections; anything before
that predates the open-world reframe (closed-set classification, belief
divergence, RISE active control) and is mostly historical.
